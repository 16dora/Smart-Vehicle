机械臂控制

上电不自动动作。输入目标后点击发送；首次请卸载连杆确认方向和行程。显示为标称目标角度，没有实际位置反馈。先发送初始角度，再按住增减按钮，每条指令目标增减 15°，本地小步平滑推进；松开保持，软件限位自动停止。
